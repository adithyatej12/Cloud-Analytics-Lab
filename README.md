# Cloud Analytics Lab

A collection of Azure Cloud Analytics and Data Engineering experiments implemented using Microsoft Azure services.

## Experiments

| No. | Experiment | Azure Services |
|---|---|---|
| 1 | Ingest data from an on-premises SQL database into Azure Blob Storage | Azure Data Factory, SQL Server, Blob Storage |
| 2 | Create an Azure Synapse Dedicated SQL Pool and load data | Azure Synapse Analytics, Dedicated SQL Pool |
| 3 | Query and analyze structured and unstructured data from Azure Data Lake Storage | Azure Synapse Analytics, ADLS Gen2, Serverless SQL |
| 4 | Azure Data Factory - On-Premises SQL Server to Azure Blob Storage | Azure Data Factory, SQL Server, Blob Storage |
| 5 | Real-time streaming data processing using Databricks and Azure Event Hub | Azure Event Hubs, Azure Databricks, ADLS Gen2 |
| 6 | End-to-end data pipeline orchestration using Azure Data Factory and Azure Databricks | Azure Data Factory, Azure Databricks, ADLS Gen2 |
| 7 | Connect Power BI to Azure SQL and create a dashboard with real-time insights | Azure SQL Database, Power BI |
| 8 | Visualize real-time data from Azure Synapse Analytics in Power BI | Azure Synapse Analytics, Power BI |
| 9 | Evaluate a full data pipeline from raw data ingestion to visualization in Power BI | Azure Data Factory, Azure Databricks, ADLS Gen2, Power BI |
| 10 | Optimize a machine learning model by tuning hyperparameters using Azure ML HyperDrive | Azure Machine Learning, HyperDrive |
| 11 | Deploy a trained machine learning model as a REST API for real-world use | Azure Machine Learning, Azure Container Instances |
| 12 | Use Azure AutoML to train and evaluate a classification model automatically | Azure Machine Learning, AutoML |
